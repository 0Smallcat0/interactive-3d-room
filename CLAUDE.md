# interactive-3d-room

This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.

- No drive-by refactors, renames or cleanups: change only what the task needs. Review the diff, not only the summary.
- Done means you actually opened `index.html` in a browser and looked at it (drag a piece, walk mode, console clean). Code that was only written or only linted is not done. There is no test suite here.
